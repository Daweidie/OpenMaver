# OpenMaver UI · 视觉设计稿

参考 Vape / Zenith 的现代极简风格：深色半透明毛玻璃、圆角面板、细霓虹描边、
高密度信息布局。全部为**正视视角、零透视**的平面设计。

当前包含两套界面：

1. **ClickGUI**：左侧分类栏 + 右侧高密度模块列表，青蓝霓虹强调。
2. **Target HUD**：锁定目标信息卡，红橙能量强调，圆形头像 + 发光环 + 渐变血条。

## ClickGUI · 画板与网格

- 画板：`1600 × 1000`（16:10）
- 面板：`1400 × 860`，圆角 `18px`，居中留白 `100 / 70`
- 分类栏：`258px`；内容区左右留白 `26px`
- 模块行：`54px` 高，行间距 `7px`，圆角 `10px`
- 展开设置区：三列网格，间距 `13 × 22`，滑块轨道 `3px`，滑块点 `10px`
- 字号：正文 `11–13px`，标题 `22px`，微型标签 `8–9px`（大写 + 字距）
- 数值、键位全部使用等宽字体

## Target HUD · 规格

- 展示尺寸 `600 × 212`（1.5×）；实际游戏 HUD `400 × 141`，圆角 `18px / 12px`
- 头像 `110px`，发光环 `136px`：3.5px 锥形渐变 + 8s 旋转，外层虚线轨道反向缓转
- 血条 `9px` 高、十段刻度；渐变 `#FF3F2E → #FFB35C`，末端高光 + 掉血残影
- 卡片：`backdrop-filter: blur(28px)`、1px 霓虹描边、内发光、四角科技括号
- 三态：默认 92% / 低血 12.5% / 满甲；低血态边框与头像环转为红色脉冲
- 动效：锁定 160ms 上浮淡入 · 丢失 220ms 收缩淡出 · 掉血残影 240ms

> 当前已接入游戏内绘制：`mc/TargetHud.java`。游戏内采用用户确认的极简版：
> 准星右侧、纯色小卡片，只保留正方形头像 / 名称 / 细血条；无头像时使用 Steve，
> 血条随血量绿→橙→深红渐变，且不再绘制头像外圈；本页面仍为完整版视觉参考。

## 交互（ClickGUI 原型）

- 顶部搜索：`⌘K` / `Ctrl K` 聚焦，实时过滤当前分类
- `ALL / ENABLED / DISABLED` 分段筛选，右侧 A–Z 排序可切换
- 左侧分类切换，强调色随分类变化
- 点击左侧圆点开关模块；点击模块行展开 / 收起设置
- 滑块可拖动，复选框可勾选；展开区数字即时更新
- 底部状态栏与右上 Profile 卡的启用数量会随开关联动

深链接（方便出图）：

```
clickgui.html?cat=render&open=esp
clickgui.html?scale=2          # 2x 导出
clickgui.html?scale=4.8        # 8K 导出
targethud.html?scale=2.4       # Target HUD 4K 导出
```

## 重新导出

```bash
./export.sh
```

依赖：`firefox`（无头截图）。脚本会为每张图创建独立临时 profile，因此不会干扰正在运行的 Firefox。
